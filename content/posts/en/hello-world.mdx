## Code Example

Here is a simple C# script that rotates an object in Unity.

```csharp
using UnityEngine;

public class Spinner : MonoBehaviour
{
    [SerializeField] private float speed = 90f; // rotation in degrees per second

    private void Update()
    {
        transform.Rotate(Vector3.up, speed * Time.deltaTime);
    }
}
```

Here is an HLSL shader function that multiplies a texture's color by a brightness value.

```hlsl
float4 ApplyBrightness(Texture2D tex, SamplerState samp, float2 uv, float brightness)
{
    float4 color = tex.Sample(samp, uv);
    return float4(color.rgb * brightness, color.a);
}
```

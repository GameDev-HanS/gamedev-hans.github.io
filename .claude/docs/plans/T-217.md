## Context
- 사용자 결정: 게임 카드의 표지를 **Steam 상점의 세로형 라이브러리 표지**로 채웁니다. 허락받은 사용은 아니며(개인 비상업 블로그, 작은 표지 + 출처 표기), 게임사가 요청하면 내립니다. ROADMAP T-217에 반영됨.
- 페이지·카드·출처 목록·검증은 이미 준비됨: `GameCard`가 `cover`를 3:4 자리에 그리고, `GameCoverCredit`이 페이지 아래 출처를 보여 주며, 로더가 파일 존재와 `coverCredit` 필수를 검사함 ([lib/games.ts](lib/games.ts)).

## 변경
1. 스크래치 폴더에 10장을 내려받아 크기(600x900 내외)·용량 확인 → `public/images/games/2026/<slug>.jpg`로 복사. 150KB를 넘으면 그대로 두지 않고 품질을 낮춰 다시 저장(라이브러리 추가 없이, 필요하면 보고)
2. [content/games/2026.json](content/games/2026.json): 게임마다 `"cover": "/images/games/2026/<slug>.jpg"`, `"coverCredit": "© <게임사>"` 추가 (다른 값은 그대로)
3. PRD 결정 사항에 표지 사용 방식 메모 (product-manager, `모드: PRD`): Steam 세로 표지, 허락 없는 사용, 출처 표기, 요청 시 내림
4. (함께 처리, 사용자 요청) 푸터의 메뉴 링크(블로그·게임·소개) 제거 — 헤더와 겹침. [site-footer.tsx](components/layout/site-footer.tsx)에서 `footerNav` 부분을 빼고 외부 링크(GitHub)와 음악 출처만 남김. PRD·ROADMAP의 푸터 설명도 같은 PRD 갱신 때 반영

## 검증
1. lint·tsc·build 통과 (로더가 10개 표지 파일·출처를 검증)
2. 빌드 결과물 + Playwright: 푸터에 GitHub 링크만 있고 메뉴 링크가 없음, `/games/2026`에서 카드 10개 모두 표지 이미지가 로드됨(`naturalWidth > 0`), 상태 배지가 표지 위에서 읽힘, 페이지 아래 출처 목록 10줄과 저작권 문구, 375px 2열, 다크·라이트
3. 리뷰 → ROADMAP 체크 → `/commit-test`

## 수정 (2026-11-09, 커밋 전 보류)

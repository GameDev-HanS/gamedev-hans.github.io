# T-307 태그 칩 목록과 태그 링크 연결

> 승인일: 2026-11-13 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
T-306에서 태그 한글 이름과 `getAllTags()`(태그별 글 수)를 만들었지만 아직 태그로 이동할 방법이 없다. 이번 작업으로 `/blog` 상단에 전체 태그 칩 목록을 두고, 글 상세의 태그 칩을 `/blog/tags/<slug>` 링크로 만든다. 태그 페이지는 T-308에서 만들며, 사용자 결정에 따라 **T-307을 끝내도 커밋하지 않고 T-308까지 이어서 한 번에 커밋**한다(그 전에는 칩 링크가 404).

## 사용자 결정 (플랜 단계)
- 글 카드의 태그 칩은 **표시만** (카드 전체가 링크라 링크 안 링크를 피함, 카드 구조·HoverCard 그대로)
- T-308까지 끝낸 뒤 함께 커밋·테스트
- `/blog` 상단 칩 맨 앞에 **'전체 n'** 칩 (`/blog`에서 강조, T-308 태그 페이지에서는 그 태그가 강조)

## 변경
1. **`components/shared/tag-list.tsx`** (새 파일, 서버 컴포넌트)
   - `TagList({ tags, linked })`: 기존 카드·상세의 `ul[aria-label="태그"]` + `Badge variant="outline"` `#{label}` 조각을 옮긴 것. `linked`면 Badge에 `render={<Link href={`/blog/tags/${slug}`} />}` (Base UI `render` prop) + `press`.
   - `TagFilter({ tags, total, current })`: `nav aria-label="태그 선택"` 안 칩 목록. 첫 칩 '전체 n'(`/blog`), 이어서 `getAllTags()` 순서(글 수 내림차순)로 `#{label} n`. `current`는 `"all"` 또는 태그 slug이고, 현재 칩은 `aria-current="page"` + 포인트 색 테두리·글자(YearTabs의 강조 방식). 나머지 칩은 `accent-hover`(테두리 포인트 색) + `press`, 키보드 포커스도 같은 강조. 모바일에서 줄바꿈(`flex-wrap`)해 가로 스크롤 없음.
2. **components/shared/post-card.tsx**: 태그 `ul`을 `<TagList tags={post.tags} />`로 교체 (링크 없음).
3. **components/sections/post-header.tsx**: `<TagList tags={post.tags} linked />`.
4. **app/blog/page.tsx**: `PageHeader` 아래 `<TagFilter tags={getAllTags()} total={posts.length} current="all" />` (글이 0개면 숨김). `getAllTags`는 `lib/posts.ts`의 것 재사용.

## 검증
- `npm run lint`, `npx tsc --noEmit`, `npm run build` 통과
- 빌드 HTML: `/blog`에 '전체 1'(aria-current)과 태그 칩 3개가 `/blog/tags/<slug>` 링크로, 글 상세 칩이 링크로, 카드 안 칩은 링크 아님
- 커밋·브라우저 테스트는 T-308 완료 후 함께

## 결정
- 2026-11-13: 글 카드의 태그 칩은 링크 없이 표시만 한다 (카드 전체가 글 상세 링크라 링크 안 링크가 되므로). 태그 이동은 `/blog` 상단 칩과 글 상세 칩으로. → T-307 완료 조건의 "목록 카드 칩을 누르면 이동"은 글 상세 칩만 해당.
- 2026-11-13: `/blog` 상단 칩 맨 앞에 '전체 n'(`/blog`) 칩. 현재 보기 강조는 "네온"이 아니라 포인트 색 테두리·글자 + `aria-current="page"` (T-127 테마 변경 반영).
- 2026-11-13: T-307은 커밋하지 않고 T-308까지 이어서 한 번에 커밋·테스트 (칩 링크가 404가 되지 않게).
- 2026-11-13 (리뷰 반영): 태그 slug `all`은 '전체' 보기와 겹치므로 예약어로 막음 — frontmatter `tags`나 `tags.json` 키에 `all`이 있으면 빌드 실패. 글 상세의 링크 태그 칩은 누르기 쉽게 높이 28px 이상(`min-h-7`), 카드 안 표시용 칩은 그대로.

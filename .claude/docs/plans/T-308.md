# T-308 태그별 글 목록 페이지

> 승인일: 2026-11-13 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
T-307에서 `/blog` 상단 태그 칩과 글 상세 태그 칩이 `/blog/tags/<slug>`로 이어지지만 그 페이지가 아직 없어 404다. 이번 작업으로 태그마다 정적 페이지를 만들어 해당 태그 글을 최신순으로 보여 준다. 사용자 결정대로 T-306·T-307 변경과 함께 커밋·테스트한다.

## 사용자 결정 (플랜 단계)
- 제목 `#<표시 이름>`(예: `#셰이더`), 설명 `'<표시 이름>' 태그 글 n개`, 브라우저 탭 `#셰이더 | HanS Dev Log`
- 별도 '전체 글' 버튼은 두지 않고 `TagFilter`의 '전체 n' 칩(`/blog`)으로 대신

## 변경
1. **lib/posts.ts**: `getPostsByTag(slug): Post[]` — `getAllPosts()`(이미 최신순)에서 그 태그가 있는 글만.
2. **app/blog/tags/[tag]/page.tsx** (새 파일) — `app/games/[year]/page.tsx` 패턴 그대로
   - `generateStaticParams`: `getAllTags().map(({ slug }) => ({ tag: slug }))`, `export const dynamicParams = false` (없는 태그·`all`은 404)
   - `generateMetadata`: `getAllTags()`에서 태그를 찾아 `{ title: "#<label>", description }`
   - 본문: `Container` > `PageHeader`(제목·설명) > `TagFilter tags={getAllTags()} total={getAllPosts().length} current={slug}` > `PostList posts={getPostsByTag(slug)}` — `app/blog/page.tsx`와 같은 구성. 글 카드 스크롤 등장(T-124)·호버는 `PostList`/`PostCard` 재사용으로 그대로 적용.
3. 헤더 "블로그" 강조는 기존 `isNavActive`가 하위 경로도 처리하므로 변경 없음 (확인만). sitemap에 태그 페이지 추가는 T-309 범위라 이번엔 하지 않음.

## 검증
- `npm run lint`, `npx tsc --noEmit`, `npm run build` 통과, 빌드 경로 목록에 `/blog/tags/[tag]` 3개
- `out/blog/tags/shader.html`(또는 폴더) 존재, 제목 `#셰이더`, `#셰이더` 칩이 `aria-current="page"`, 글 카드 1개
- 이어서 `/commit-test`로 T-306~T-308을 함께 브라우저 테스트(태그 칩 → 태그 페이지 이동, `/blog/tags/no-such` 404, 모바일 가로 스크롤 없음) 후 커밋

## 결정
- 2026-11-13: 태그 페이지 제목은 `#<표시 이름>`, 설명은 `'<표시 이름>' 태그 글 n개`. 완료 조건의 "전체 글" 버튼은 두지 않고 `TagFilter`의 '전체 n' 칩(`/blog`)으로 대신한다.
- 2026-11-13: sitemap에 태그 페이지 추가는 T-309에서 (이번 범위 아님).

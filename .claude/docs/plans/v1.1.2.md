# v1.1.2 (T-315) 게임 페이지 영어판 `/en/games`

> 승인일: 2026-11-14 · 로드맵: [ROADMAP](../ROADMAP.md)

## 배경

EN 모드에서 헤더 Games를 누르면 한국어 게임 페이지로 가서 화면이 한글로 나온다 (v1.1.0에서는 범위 밖). `/en/games`, `/en/games/<연도>`를 정적 페이지로 만들고 화면 문구와 게임 이름을 영어로 보여 준다. 같은 계열(영어판)이므로 버전은 **v1.1.2**.

사용자 결정 (2026-11-14):
- 게임 이름: JSON에 선택 필드 `titleEn`을 넣고 Claude가 공식 영문 이름을 채움. 없으면 `title` 그대로
- 영어 소감: 같은 파일에 선택 필드 `commentEn`. `comment`가 있는데 `commentEn`이 없으면 영어 페이지에서는 소감을 숨김 (빌드 실패 아님)

## 데이터

- `lib/games.ts` 스키마에 `titleEn`, `commentEn`(선택, 빈 문자열 금지) 추가. `commentEn`만 있고 `comment`가 없으면 빌드 실패
- `content/games/2026.json`, `earlier.json`에 `titleEn` 채우기 (이미 영어 이름인 Escape from Duckov, Slay the Spire 2, DJMAX RESPECT V는 생략)
- `coverCredit`은 그대로 표시 (지금 표지 없음)

## 코드

- `lib/i18n.ts` `UI`에 게임 문구 추가 (ko/en): 페이지 제목·설명, 상태 이름, 상태 없음 묶음, 빈 목록, PV 안내, 표지 저작권 문구, 전체/All, aria 문구, 플레이 시간, 별점 낭독, PV 보기·닫기·YouTube에서 보기, 플랫폼 이름(`모바일` → `Mobile`)
- `lib/game-status.ts`: `STATUS_LABEL` 대신 `UI[locale].gameStatus`
- `lib/games.ts`: `localizeGames(games, locale)`, `groupGames(games, locale)`/`countGroups` 언어별 묶음 이름·정렬
- 게임 컴포넌트에 `locale` prop(기본 `"ko"`)
- 새 페이지 `app/en/games/page.tsx`, `app/en/games/[year]/page.tsx`, 한국어 게임 페이지에도 hreflang
- `config/site.ts` games `hasEnglish: true`, `language-toggle.tsx` 게임 주소 짝, `app/sitemap.ts` 영어 연도 페이지
- `docs/writing-posts.md` 필드 표, 버전 1.1.2 (`package.json`, `package-lock.json`, `CHANGELOG.md`)

## 검증

- lint, tsc, build → `out/en/games.html`, `out/en/games/2026.html`
- `commentEn`만 있는 게임으로 빌드 실패 메시지 확인 후 되돌림
- Playwright: `/en/games` 한글 없음, 연도 탭·PV 팝업 영어, 헤더 Games → `/en/games`, KR/EN 전환 짝, 한국어 `/games` 그대로, 모바일 가로 스크롤 없음, 콘솔 오류 없음

## 결정

- 2026-11-14: 게임 이름은 선택 필드 `titleEn`(공식 영문 이름, Claude가 19개 채움 — 이미 영어인 Escape from Duckov·Slay the Spire 2·DJMAX RESPECT V는 생략). 없으면 `title` 그대로 (사용자 결정)
- 2026-11-14: 영어 소감은 같은 파일의 선택 필드 `commentEn`. 없으면 영어 페이지에서 소감 숨김, `comment` 없이 `commentEn`만 있으면 빌드 실패 (사용자 결정)
- 2026-11-14: 영어 페이지 플랫폼 표기 `모바일` → `Mobile`. 표지 출처 `coverCredit`은 데이터 그대로 표시하고 가이드에 영문 표기 권장 (리뷰 사소 2건 반영: platformName 조회 `Object.hasOwn`, 가이드 문구)

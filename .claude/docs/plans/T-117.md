# T-117 배경 음악 Provider와 헤더 음악 버튼

> 승인일: 2026-11-09 · 로드맵: [ROADMAP](../ROADMAP.md)

## 변경
- 새 `components/providers/bgm-provider.tsx` ("use client")
  - props `src: string | null`. `null`이면 자식만 렌더
  - `<audio src preload="none" loop>`를 루트 레이아웃에 한 번만 → 클라이언트 이동에도 유지(이어서 재생)
  - 컨텍스트 `{ available, playing, toggle }` + `useBgm()`. 항상 꺼짐에서 시작, 저장소에 아무것도 저장 안 함
  - `toggle`: 재생 중이면 `pause()`, 아니면 `play()` 성공 시 켜짐 / 거부 시 꺼짐 유지(콘솔 오류 없음). `pause` 이벤트로 상태 동기화
- 새 `components/shared/bgm-toggle.tsx` ("use client"): 음원 없으면 `null`. ghost 아이콘 버튼, 꺼짐 음소거 / 켜짐 음표 + 네온 시안 글로우, `aria-label`·`aria-pressed`
- `app/layout.tsx`: `getBackgroundMusic()` 한 번 호출 → `BgmProvider src`, `SiteFooter music`. Provider는 ThemeProvider 안, 헤더·본문·푸터 바깥 (페이지 전환 래퍼 T-122보다 바깥)
- `components/layout/site-header.tsx`: 테마 토글 옆에 `BgmToggle`

## 결과 (2026-11-09)
임시 무음 mp3(스크래치에서 생성)와 임시 `music.json`으로 Playwright 확인 후 둘 다 삭제함.
- 음원 없음: 빌드 HTML에 `<audio>`·버튼·출처 없음, 클라이언트 JS에 `content/music.json` 문자열 없음
- 첫 로드 꺼짐(`aria-pressed=false`), `preload="none"`이라 켜기 전 `/audio/` 요청 없음
- 클릭 → 재생(`paused=false`), "배경 음악 끄기"·네온 아이콘 / 다시 클릭 → 정지
- 켠 채로 헤더 "소개" 이동 → 같은 `<audio>` 요소가 계속 재생
- 새로고침 → 꺼짐, localStorage·sessionStorage·쿠키 비어 있음
- Enter·Space로 켜기/끄기
- 깨진 mp3 → 재생 거부(MediaError 4), 꺼짐 유지, 콘솔 오류·경고 없음
- 375px: 버튼 보임, 가로 스크롤 없음
- 참고: 첫 시도에서 버튼 클릭 후 페이지가 `/blog`로 이동한 적이 1번 있었으나, 버튼 위 겹친 요소 없음을 확인했고 같은 조건으로 다시 해도 재현되지 않음 (이전 테스트의 브라우저 상태가 남은 것으로 추정)

## 수정 (2026-11-09, 리뷰 반영)
- 재생 실패 시 `audio.pause()`로 audio 상태도 되돌림 → 깨진 음원에서 두 번째 클릭도 다시 재생 시도 (이전엔 두 번 눌러야 했음). 정상 재생·정지는 그대로임을 다시 확인
- `lib/music.ts`: `sourceUrl`은 http·https만 허용(`data:` 출처면 빌드 실패 확인), `import "server-only"` 추가 (클라이언트에서 import하면 빌드 오류 확인)
- `CLAUDE.md`: providers는 layout·shared에서 훅으로 import 가능하다고 명시
- 재리뷰: 문제 없음. 참고 메모(결함 아님): 켜기 → 끄기 → 곧바로 켜기를 아주 빠르게 하면, 브라우저 처리 순서에 따라 첫 재생의 거부 콜백(`AbortError`)이 새 재생을 멈출 수 있음. 실제로 생기면 `err.name === "AbortError"`일 때 `pause()`를 건너뛰거나 요청 번호로 최신 요청만 처리

## 검증 (임시 음원으로, 확인 후 삭제·커밋 안 함)
- 첫 로드 꺼짐, 클릭 → 재생·아이콘/aria 변경, 다시 클릭 → 정지
- 켠 채로 메뉴 이동 → 계속 재생 / 새로고침 → 꺼짐, 저장소·쿠키에 값 없음
- 켜기 전 오디오 요청 없음, 깨진 mp3면 꺼짐 유지·콘솔 오류 없음

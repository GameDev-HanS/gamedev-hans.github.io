# T-115 sitemap에 글 경로 추가와 첫 배포 점검

> 승인일: 2026-11-09 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- 사용자 결정: 게임 페이지(T-213)가 생길 때까지 '게임' 메뉴를 헤더·푸터·모바일 메뉴·sitemap에서 숨김 → 지금 푸시해도 깨진 링크 없음
- 같은 턴에 받은 2026 게임 기록은 `content/games/2026.json`에 저장 (T-209~에서 사용). 클리어 안 한 게임에도 끝낸 날짜가 있어 `clearedAt` 대신 `endedAt`, `status`는 선택(`cleared`/`playing`만, 나머지는 표시 안 함), 평점·소감 비움, Slay the Spire 2는 날짜 없음 → T-209 때 PRD·ROADMAP에 반영

## 변경
- `config/site.ts`: `mainNav`에서 '게임' 제거 (T-213에서 다시 추가)
- `app/sitemap.ts`: 메뉴 경로 + 글 URL(`/blog/<slug>`, `lastModified` = 글 날짜)
- 빌드 결과물(`out/`)을 의존성 없는 Node 정적 서버로 띄워 브라우저 확인 (개발 서버 자동 새로고침 영향 배제)
- 참고: 소개 페이지는 아직 스타터킷 설명 → 단계 2(T-201~)에서 교체

## 검증
- `out/sitemap.xml`: `/`, `/blog`, `/about`, `/blog/hello-world` (`/games` 없음)
- 정적 서버 + Playwright 기본 테스트

## 점검 결과 (2026-11-09)
- lint·typegen·tsc·build 통과, `out/sitemap.xml`에 4개 경로 (`/games` 없음), robots.txt에 sitemap 주소 있음
- 빌드 결과물 브라우저 확인 통과: 홈(이름·소개·최근 글 카드·"전체 글 보기" → `/blog`), 헤더·푸터·모바일 메뉴에 '게임' 없음, 블로그 목록 → 글 → 목록으로, `/games` 404 화면, 테마 유지(라이트로 바꾼 뒤 이동해도 유지), 375px 가로 넘침 없음
- 참고: Windows에서 빌드하면 링크 미리 불러오기 파일(`__next.<경로>.__PAGE__.txt`)이 하위 폴더로 저장돼 404가 남. Next.js 내보내기가 Windows 경로 구분자(`\`)를 `.`으로 바꾸지 못하는 문제(`node_modules/next/dist/export/index.js`). 배포 CI는 ubuntu에서 빌드하므로 실제 사이트에는 영향 없고, 로컬에서도 미리 불러오기만 실패할 뿐 페이지 이동은 정상
- 판단: 첫 배포(푸시) 가능. 소개 페이지는 스타터킷 설명이 그대로 공개됨 (T-201~에서 교체)

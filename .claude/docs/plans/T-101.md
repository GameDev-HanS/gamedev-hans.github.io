# T-101 스타터킷 데모 페이지·섹션 제거

> 승인일: 2026-11-08 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- 로드맵 첫 작업. 블로그로 바꾸기 전에 스타터킷 전용 데모(컴포넌트 쇼케이스 페이지, 예제 폼, 홈의 기술 스택·CTA 섹션)를 걷어 낸다.
- 완료 조건(ROADMAP): `/components`가 빌드 결과에서 사라져 404, 데모 섹션 import 없음, lint·tsc·build 통과, 안 쓰게 된 패키지는 지우지 않고 목록만 남김.

## 삭제
- `app/components/page.tsx` (폴더째) — 데모 페이지
- `components/sections/component-showcase.tsx`, `components/sections/example-form.tsx` — 위 페이지 전용
- `components/sections/features.tsx`, `components/sections/cta.tsx` — 홈의 스타터킷 홍보 섹션 (재사용할 내용 없음, 블로그 홈은 이후 작업에서 새로 만듦)
- `components/ui/*`는 그대로 둔다 (shadcn 컴포넌트 라이브러리, 이후 카드·배지 등에 재사용)

## 수정
- `app/page.tsx`: `Features`, `Cta` import와 사용 제거 → `<Hero />`만 남김 (홈 본격 개편은 로드맵의 홈 작업에서)
- `components/sections/hero.tsx`: `/components`로 가는 "컴포넌트 보기" 버튼 제거, "소개" 버튼 하나만 남김. 문구는 T-102·홈 작업에서 바꿈
- `config/site.ts`: `mainNav`에서 "컴포넌트" 항목 제거 (메뉴·sitemap에 404 링크가 남지 않게). 나머지 메뉴 정리는 T-102
- `CLAUDE.md`: 삭제되는 `example-form.tsx` 링크를 빼고 "폼은 클라이언트에서만 처리 (zod 검증 후 toast)" 원칙만 남김
- `.claude/commands/test.md`: 기본 테스트 표에서 `/components` 행 제거 (폼 검사는 "폼이 있는 경우" 그대로)

# v1.1.0 (T-313) 영어판 — 홈 소개 + 블로그 글 번역

> 승인일: 2026-11-14 · 로드맵: [ROADMAP](../ROADMAP.md)

## 배경

사용자 요청: KR / ENG 두 언어만 지원 (JP는 제외). 영어판 문서는 Claude가 직접 번역해 추가하고, 한글 → 영어 번역이 이상하지 않은지 검사한다. 홈의 소개 부분도 영어로 보여 준다.
정적 내보내기라 방문자가 보는 순간에 번역할 서버가 없으므로, **번역본 파일을 저장소에 미리 넣고 빌드 때 페이지로 만든다**. 외부 번역 API·비밀값은 쓰지 않는다.

## 범위

- 주소: 한국어는 그대로, 영어는 `/en`(홈), `/en/blog`(번역된 글 목록), `/en/blog/<slug>`(번역된 글)
- 게임·태그 페이지는 영어판 없음. 영어 글의 태그 칩은 링크 없이 영문 slug로 표시
- 영어 페이지에서는 그 페이지 화면 문구도 영어 (섹션 제목, 버튼, 이전/다음 글, 목록으로), 헤더 메뉴 이름도 Home / Blog / Games (Games는 한국어 페이지로 연결)
- 헤더 KR / EN 전환 버튼: 지금 페이지의 짝 페이지로 이동, 짝이 없으면 `/en/blog` 또는 `/en`
- `/blog` 카드에 번역본이 있으면 "EN" 표시, 글 상단에 "Read in English" / "한국어로 읽기"
- 영문 표기: 이름 **Hanseung Kim**, 회사 **Vic Game Studio** (사용자 확인)

## 콘텐츠

- `content/posts/en/<slug>.mdx`: frontmatter는 title·summary만 (날짜·태그·대표 이미지는 원문). 원문 없는 slug는 빌드 실패
- `content/en/profile.json`: name·tagline·interests·studying만 (사진·링크는 한국어 파일)
- `content/en/timeline.json`: 한국어와 항목 수·순서·type이 같아야 함 (다르면 빌드 실패)

## 코드

- `lib/i18n.ts`: `Locale`, 화면 문구 사전 `UI`, `localePath`, `isEnglishPath` (라이브러리 없이 객체 — 문구가 적고 라우팅을 `/en` 폴더로 직접 나눔)
- `lib/posts.ts`: `Post.hasEnglish`, `getAllEnglishPosts`, `getEnglishPostBySlug`, `getAdjacentEnglishPosts`
- `lib/content.ts`: `getProfile(locale)`, `getTimeline(locale)` + 영어판 검증
- 섹션·카드 컴포넌트에 `locale` prop (기본 `"ko"`), 본문 서식은 `components/shared/post-prose.tsx`로 공용화
- `app/en/` (layout: `<div lang="en">`, page, blog/page, blog/[slug]/page)
- `components/shared/language-toggle.tsx`, `config/site.ts`의 `mainNav`에 `titleEn`·`hasEnglish`, `lib/nav.ts`의 `getNavItems`
- `lib/metadata.ts`에 `locale`·`languages`(hreflang + x-default), `app/sitemap.ts`에 영어 페이지와 alternates

## 검증

- lint, tsc, build 통과 (`out/en.html`, `out/en/blog.html`, `out/en/blog/hello-world.html`)
- 원문 없는 영어 글, 항목 수가 다른 영어 timeline → 빌드 실패 메시지 확인 후 되돌림
- Playwright: `/en` 영어 섹션 5개·한글 없음, 전환 버튼 짝 페이지, `/blog` EN 칩, 영어 글 링크가 `/en` 아래, 모바일 가로 스크롤 없음, 콘솔 오류 없음

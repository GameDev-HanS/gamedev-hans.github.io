# T-109 글 데이터 로더와 샘플 글

> 승인일: 2026-11-09 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- T-108에서 MDX 방식 확정. 글 목록·상세가 쓸 데이터 로더를 만들고 샘플 글을 2개로 늘린다.
- PRD 데이터 모델(글): `slug`(파일 이름), `title`, `date`(YYYY-MM-DD), `summary`, `tags`(영문 slug 배열), `thumbnail`(선택). 사진은 `public/images/posts/<slug>/`.
- T-108 리뷰에서 넘긴 3건 포함: 제목 누락 시 "undefined" → 검증으로 빌드 실패, 글 폴더 없음·글 0개 동작 확인, `@types/mdx` 위치.

## 변경
- 새 `lib/posts.ts` (`server-only`, fs + gray-matter + zod)
  - `getAllPosts()`: 날짜 내림차순(같으면 slug순), 폴더 없으면 빈 배열
  - `getPostBySlug(slug)`: `Post | null`
  - 검증 실패 시 `content/posts/<파일>: <항목>: <이유>`로 빌드 실패
    - 파일 이름(slug)·`tags` 각각 `^[a-z0-9]+(-[a-z0-9]+)*$`, `tags` 1개 이상
    - `title`·`summary` 빈 문자열 불가, `date`는 Date·문자열 모두 받아 `YYYY-MM-DD`로 정규화
    - `thumbnail`(선택): `/images/posts/`로 시작, `..` 금지, `public/`에 실제 파일 필요
- `app/blog/[slug]/page.tsx`: 로더 사용으로 교체 (화면 본격 구현은 T-112)
- 샘플 글: `hello-world.mdx`(2026-11-09) + 새 `game-loop-basics.mdx`(2026-11-05, 썸네일·본문 이미지 1장), 직접 그린 SVG 이미지 2개
- `@types/mdx`를 devDependencies로 이동

## 결과 (2026-11-09)
- 빌드: `● /blog/hello-world`, `● /blog/game-loop-basics` (최신순), 이미지 2개 `out/images/posts/game-loop-basics/`에 복사, 본문 `<img>`·`<ol>`·`<blockquote>` 정상
- 검증 실패 5종 모두 빌드 실패 + 파일 이름 포함 메시지
  - `tags: [셰이더]`, `tags: [Shader]` → "tags.0: 영문 소문자·숫자·하이픈만 쓸 수 있습니다"
  - `summary` 누락 → "summary: 필수 항목입니다 (예: summary: 한 줄 요약)" (zod 기본 영어 메시지 대신 한국어 안내로 바꿈)
  - 없는 `thumbnail` → "thumbnail 파일이 없습니다 — public/images/posts/nope/x.png"
  - `Bad-Upper-Name.mdx` → "파일 이름은 영문 소문자·숫자·하이픈만 쓸 수 있습니다"
- **글 0개면 빌드 실패**: 본문 동적 import(`@/content/posts/${slug}.mdx`)에 맞는 파일이 하나도 없으면 Turbopack이 "Module not found"로 실패. → 규칙: `content/posts/`에 글을 항상 1개 이상 둠 (작성 가이드 T-311에도 적을 것)
- `@types/mdx`를 devDependencies로 이동

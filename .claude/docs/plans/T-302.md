# T-302 이전/다음 글 링크

> 승인일: 2026-11-13 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
ROADMAP 다음 작업(P0·S). 글 상세 하단에 날짜순 이전·다음 글로 갈 수 있게 한다. 지금 글은 `hello-world.mdx` 하나뿐이라 배포 화면에는 링크가 나오지 않고(글이 하나면 섹션 자체를 숨김), 확인은 임시 글로만 한다.

## 결정 (사용자)
- 모양: 테두리 있는 칸 2개(`accent-hover`), 왼쪽 "← 이전 글" / 오른쪽 "다음 글 →" 라벨 아래 제목. 모바일 1열, `sm` 이상 2열.
- 방향: 이전 = 더 오래된 글, 다음 = 더 최근 글. 가장 오래된 글엔 이전 칸, 최신 글엔 다음 칸이 없음.
- 위치: 본문 `article` 아래, "목록으로" 버튼 위.
- 확인용 두 번째 글은 임시로만 넣고 커밋 전에 지움.

## 변경
1. `lib/posts.ts` — `getAdjacentPosts(slug): { prev: Post | null; next: Post | null }` 추가. `getAllPosts()`(최신순, 같은 날은 slug순) 안에서 인덱스를 찾아 `prev = posts[i + 1]`(더 오래된), `next = posts[i - 1]`(더 최근). 없으면 둘 다 null.
2. `components/sections/post-nav.tsx` (서버 컴포넌트, 새 파일) — `{ prev, next }`를 받아 둘 다 없으면 `null`. `<nav aria-label="이전·다음 글">` 안 2열 그리드. 각 칸은 `next/link` + 테두리 + `accent-hover`, 라벨은 `text-xs text-muted-foreground` + lucide 화살표(aria-hidden), 제목은 `line-clamp-2`. 다음 칸은 `sm:col-start-2 sm:text-right`로 이전 칸이 없어도 오른쪽에 붙음.
3. `app/blog/[slug]/page.tsx` — `getAdjacentPosts(slug)`로 받아 하단 `border-t` 영역에서 PostNav → "목록으로" 순서로 배치.

계층 규칙(`ui` ← `shared` ← `sections` ← `app`) 지킴, 새 라이브러리 없음, 클라이언트 JS 없음.

## 확인
- `npm run lint`, `npx tsc --noEmit`
- 임시로 `content/posts/tmp-second.mdx`(날짜가 더 최근, 태그 영문 slug)를 넣고 개발 서버에서:
  - `/blog/hello-world`: "다음 글"만 보이고 임시 글로 이동
  - `/blog/tmp-second`: "이전 글"만 보이고 hello-world로 이동
  - 375px에서 가로 스크롤 없음, 다크·라이트 모두 깨지지 않음
- 임시 글을 지우고 `/blog/hello-world`에 nav가 없는지 확인 (빌드 통과)

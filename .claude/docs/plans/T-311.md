# T-311 운영자용 글 작성 가이드

> 승인일: 2026-11-14 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
글·영상·게임 기록·배경 음악은 코드 수정 없이 파일만 추가하면 반영되지만, 규칙(태그 slug, 표지 폴더, Supabase 파일 이름, music.json 필드 등)이 로드맵·계획 문서와 코드 곳곳에 흩어져 있다. 운영자가 한 문서만 보고 콘텐츠를 추가할 수 있게 `docs/writing-posts.md`를 만든다. 코드 변경 없음.

## 만들 파일
- **새 파일** `docs/writing-posts.md` (한국어, 운영자용)
- **README.md** "콘텐츠 추가" 섹션 끝에 가이드 링크 한 줄 추가

## 문서 구성 (실제 코드 규칙 기준)
1. **한눈에 보기** — 무엇을 어디에 두는지 표 + 커밋·푸시하면 GitHub Actions가 다시 빌드, 형식이 틀리면 빌드 실패(오류에 파일 이름)
2. **새 글 쓰기** (`lib/posts.ts`) — 파일 이름 slug, frontmatter 예시(title, date, summary, tags 1개 이상·영문 slug·중복 금지·`all` 금지, thumbnail 선택), 표·코드 블록 언어, `npm run dev` 미리 보기
3. **태그 한글 이름** — `content/tags.json`
4. **사진** — `public/images/posts/<slug>/`, WebP·가로 1600px 이하
5. **영상** (T-303·T-304) — ffmpeg `+faststart` 예시, 50MB 이하, 파일 이름 영문·숫자·`-`·`_`, Supabase `videos` 버킷 업로드·공개 URL, `<Video src title poster? captions?>`, "영상" 표시 자동, 무료 플랜 주의
6. **게임 기록** (`lib/games.ts`) — 연도 파일·`earlier.json`, 필드 예시, 플랫폼 표기 순서, 해를 넘긴 게임, earlier 중복 slug 실패, 표지 600px·폴더
7. **배경 음악** (`lib/music.ts`) — 음원 선택, `public/audio/`, `music.json` 예시, `file` 일치, 재빌드 필요
8. **기타** — `PAGES_BASE_PATH` 형식
9. **빌드 실패했을 때** — 오류 줄 찾기, 자주 나는 오류

## 검증
- 문서 예시를 `lib/posts.ts`·`lib/games.ts`·`lib/music.ts`·`components/shared/video.tsx` 스키마와 대조
- `npm run lint`, `npx tsc --noEmit` 통과

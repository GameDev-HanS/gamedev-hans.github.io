# T-102 사이트 설정을 블로그용으로 변경

> 승인일: 2026-11-08 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- T-103과 함께 진행. 결정: 블로그 이름 **HanS Dev Log**, 설명 **"게임 개발과 나의 일상 기록"**.

## 변경
- `config/site.ts`
  - `name: "HanS Dev Log"`, `description: "게임 개발과 나의 일상 기록"`
  - `mainNav`: 홈(`/`) · 블로그(`/blog`) · 게임(`/games`) · 소개(`/about`) 4개. `/blog`, `/games`는 각 페이지 작업 전까지 404 (ROADMAP에서 허용)
  - (계획 승인 직후 사용자가 "플레이 게임" 페이지를 추가하고 헤더 메뉴에 넣기로 결정 → 게임 메뉴 포함. PRD·ROADMAP 반영은 product-manager가 진행)
  - `links.github`는 그대로
- `app/layout.tsx`: 메타데이터는 이미 `siteConfig`를 쓰므로 수정 없음 (확인만)
- `components/sections/hero.tsx`: 스타터킷 홍보 문구 정리 (T-101 리뷰 사소 지적)
  - 배지 "Next.js 16 · App Router" → "Game Dev Log", 제목 → "HanS Dev Log", 본문 → `siteConfig.description`만 (뒤의 "레이아웃, 다크 모드, 폼 검증…" 문장 삭제)
  - 버튼 하나뿐이라 의미 없는 `flex flex-wrap gap-2` 감싸개 제거
  - 홈 본격 디자인은 로드맵의 홈 작업에서
- 헤더·모바일 메뉴·푸터·sitemap은 `siteConfig`를 그대로 쓰므로 자동 반영

## 검증
1. `npm run lint`, `npx tsc --noEmit`, `npm run build` 통과
2. `out/index.html`에 "HanS Dev Log", 설명 문구가 있고 스타터킷 문구("폼 검증", "스타터킷")가 없음
3. `out/sitemap.xml`에 `/`, `/blog`, `/about` 3개

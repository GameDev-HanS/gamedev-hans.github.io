# T-305 목록 카드 "영상 포함" 표시

> 승인일: 2026-11-14 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
PRD F006: 블로그 목록 카드에 영상 포함 표시. T-304로 `<Video>`가 생겼고 샘플 글 hello-world에 영상이 있다. frontmatter 필드 없이 빌드 시 본문을 검사해 `hasVideo`를 계산한다(ROADMAP 2장 결정).

## 변경
1. `lib/posts.ts`
   - `readPost`에서 `matter()`의 `content`도 받아 `hasVideo` 추가, `Post` 타입에 `hasVideo: boolean`
   - `hasVideoTag`: 펜스 코드 블록(``` / ~~~, 여는 펜스 길이 이상으로 닫힘), 인라인 코드, JSX 주석(`{/* */}`)을 지운 뒤 `/<Video[\s/>]/` 검사 — 코드 예시 안의 `<Video`는 세지 않음
2. `components/shared/post-card.tsx`
   - `hasVideo`면 썸네일 왼쪽 위에 작은 배지(lucide `PlayIcon` + "영상"), 반투명 검정 배경 + 흰 글자
   - 홈 최근 글·/blog·태그 페이지가 모두 PostCard를 써서 한 번에 적용

## 검증
- lint·tsc·build, `out/blog.html`·`out/index.html`에 배지 있음
- 임시로 코드 블록 안에만 `<Video`가 있는 글을 넣어 배지가 없는지 확인 후 삭제

## 결정
- 2026-11-14 리뷰(사소 3건: 인라인 코드 정규식이 문단을 넘음, 같은 줄에서 열고 닫는 백틱 펜스, 목록·인용 안 펜스) → 정규식 검사를 버리고 **MDX 문법 트리**로 교체: `unified` + `remark-parse` + `remark-mdx`로 본문을 읽고 `unist-util-visit`로 `mdxJsxFlowElement`/`mdxJsxTextElement` 중 이름이 `Video`인 요소를 찾는다. 코드 블록·인라인 코드·`{/* */}` 주석은 JSX 요소가 아니어서 자연히 제외. MDX 문법 오류는 파일 이름을 붙여 빌드 실패.
  - 의존성: 네 패키지를 `package.json`에 명시 (이미 `@next/mdx`/`@mdx-js`가 같은 버전을 설치해 둔 것, 직접 import하므로 명시)
  - 검증: 음성 임시 글(인라인 코드, JSX 주석, 목록 들여쓰기 펜스, 인용 펜스, ~~~ 펜스) 배지 없음 / 양성 임시 글(짝 없는 백틱 뒤 실제 `<Video>`)·hello-world 배지 있음. 임시 글 삭제 후 빌드 통과
- 2026-11-14 재리뷰(사소 2건) → 수정: ① 검사 파서에 `remark-gfm` 추가(MDX 빌드와 같은 문법), ② 본문 내용을 키로 결과를 모듈 `Map`에 기억해 빌드 중 페이지마다 다시 해석하지 않음. 중복 타입 검사(`"name" in node`) 제거. 표 안 인라인 코드 `<Video />` 포함 음성 글 배지 없음·양성 글 배지 있음 재확인
- 2026-11-14: 배지는 썸네일 왼쪽 위 "▶ 영상"(반투명 검정 + 흰 글자). 홈 최근 글·/blog·태그 페이지 공통(PostCard)

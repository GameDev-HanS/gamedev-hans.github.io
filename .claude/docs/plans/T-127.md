## 효과 유틸리티 정리
- 삭제: `--neon-cyan`, `--neon-magenta`, `--neon-*-glow` 변수와 `neon-glow`, `neon-glow-magenta`, `neon-text`, `neon-text-magenta` 유틸리티
- `neon-hover` → **`accent-hover`**: 호버·키보드 포커스 시 테두리가 primary로 바뀌고 아주 옅은 그림자. `!important`·동작 줄이기 처리는 유지
- 포인트 색은 모두 기존 `primary` 토큰 (`text-neon-cyan` → `text-primary`)

## 사용처 수정
- hero: 제목 본문색 + 끝의 시안 점, 글로우 제거, 소개 버튼 `accent-hover`
- main-nav·mobile-nav: 현재 메뉴 `text-primary` (글로우 제거)
- site-header 로고 아이콘, site-footer·music-credit·recent-posts 호버: `text-primary`
- bgm-toggle: 켜짐 아이콘 `text-primary`, drop-shadow 제거
- post-card: `accent-hover`, 썸네일 없음 배경 `from-primary/15 via-card to-card`, 제목 호버 `text-primary`, 제목 단계를 prop으로 (홈 최근 글은 h3, T-114 리뷰 반영)
- 글 상세: 본문 링크 `prose-a:text-primary`, 인용 테두리 `border-primary`, 목록으로 버튼 `accent-hover`
- 404: GAME OVER 유지, 마젠타·글로우 → 본문색, 버튼 `accent-hover`

## 글꼴
- `html`의 `font-mono` → `font-sans`, `--font-heading`을 Geist Sans로
- Mono를 남길 곳: 헤더 로고, 날짜, 태그, 히어로 배지, 404 라벨, 본문 코드

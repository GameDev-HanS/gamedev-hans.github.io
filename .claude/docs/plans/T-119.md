# T-119 Motion 설치, 공통 애니메이션 래퍼, 동작 줄이기 기반

> 승인일: 2026-11-09 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- 단계 1의 마지막 에픽(1.8 모던 UI 애니메이션)의 기반 작업입니다. 이후 T-121~T-126과 게임·소개 페이지가 같은 래퍼를 씁니다. 단계 1이 끝나야 소개 페이지 작업(T-201~)이 열립니다.
- 사용자 결정: 세기는 **은은하게**(Linear·Vercel 느낌), 확인용으로 **홈 히어로에 바로 적용**(홈 전체 연출은 T-123).
- 확인함: `motion` 14.11.1, peerDependencies `react`/`react-dom` ^19 지원(`remix`는 선택 항목). React 19.3.1·Next 16.4.5.

## 변경
1. `npm install motion` (dependencies)
2. `lib/motion.ts`: `DURATION = 0.35`초, `DISTANCE = 10`px, `STAGGER = 0.06`초, `EASE = [0.22, 1, 0.36, 1]`. 이동은 `y`(transform)와 `opacity`만
3. `components/providers/motion-provider.tsx`: `MotionConfig reducedMotion="user"` + 기본 transition
4. `components/shared/motion/`: `FadeIn`(마운트 시 등장), `Stagger`·`StaggerItem`(차례 등장), `Reveal`(화면에 들어올 때 한 번). 이 파일들만 `"use client"`
5. `app/layout.tsx`: `ThemeProvider` 안쪽을 `MotionProvider`로 감쌈
6. `components/sections/hero.tsx`: 배지·제목·소개·버튼 줄을 `Stagger`/`StaggerItem`으로 (서버 컴포넌트 유지)

## 검증
1. `npm install` peer 경고 없음, lint·typegen·tsc·build 통과
2. `out/index.html`에 히어로 문구가 그대로 있음
3. Playwright(빌드 결과물): opacity 0→1·y 10px→0, 항목 간 약 0.06초 차이 / 동작 줄이기에서는 opacity만 / 다크·라이트·375px 레이아웃 유지

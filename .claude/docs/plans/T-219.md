# T-219 게임 '전체' 보기와 게임 12개 추가

> 승인일: 2026-11-09 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- 사용자가 게임 12개를 더 알려 줌. 일부는 2026년 이전에만 플레이해 연도별 페이지에 넣을 수 없음.
- 사용자 결정: 연도 목록에 **'전체' 보기**를 추가 — 전체에는 지금까지 한 모든 게임(2026 이전 포함), 연도별에는 그해에 플레이한 게임만. 헤더 '게임' → **전체가 기본**(/games). 플랫폼은 **한글(PC (Steam) · PC · 모바일)**. 끝나지 않은 게임('2026 ~')은 **상태 없이**. 몬스터 헌터는 **월드: 아이스본**. 슬레이 더 스파이어 2는 이미 2026에 있음(그대로).
- 함께 커밋: 아직 커밋하지 않은 T-218(PV 팝업)도 이번 커밋에 같이 들어감.
- 재사용: [lib/games.ts](lib/games.ts)의 `readGamesDir`·스키마·`groupGames`, [game-year-view.tsx](components/sections/game-year-view.tsx), [year-tabs.tsx](components/shared/year-tabs.tsx), PV 찾기 스크립트(스크래치 `pv/find-pv.ps1`, 공식·인증 채널 + oEmbed 임베드 확인).

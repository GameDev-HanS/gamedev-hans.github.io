# T-116 배경 음악 데이터 로더와 음원 유무 판정

> 승인일: 2026-11-09 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- T-116~T-118(배경 음악, F015)을 한 계획으로 승인받아 진행. 음원은 사용자가 나중에 `content/music.json` + `public/audio/*.mp3`로 넣음.

## 변경 — 새 `lib/music.ts` (서버 전용, fs)
- `getBackgroundMusic(): BackgroundMusic | null`
  - `content/music.json` 없음 → `null` (지금 상태, 빌드 통과)
  - JSON 파싱 실패·zod 검증 실패 → `content/music.json`이 들어간 메시지로 throw (빌드 실패)
    - 스키마: `file`(`/`·`..` 금지, `.mp3`만), `title`·`artist`·`source`·`license`(빈 문자열 불가), `sourceUrl`(선택, URL)
  - `public/audio/<file>` 없음 → `null`
  - 있으면 `{ src: "${PAGES_BASE_PATH}/audio/<file>", title, artist, source, sourceUrl?, license }`
- 서버 컴포넌트(`app/layout.tsx`)에서만 import (처음 계획은 `server-only` 미추가였으나, 리뷰 반영으로 `server-only`를 추가함 — T-117.md "수정" 참고)

## 결과 (2026-11-09)
- `file: "../x.mp3"` → 빌드 실패 "content/music.json: 배경 음악 정보가 올바르지 않습니다 — file: public/audio/ 안의 mp3 파일 이름만 적습니다"
- `title: ""` → 빌드 실패 "content/music.json: … title: Too small…"
- 올바른 `music.json` + mp3 없음 → 빌드 통과, `<audio>` 없음
- 확인용 임시 파일은 모두 삭제

## 검증
- 음원 없음: 빌드 통과, `<audio>`·버튼·출처 없음
- 잘못된 `music.json`(예: `file: "../x.mp3"`) → 파일 이름 메시지와 함께 빌드 실패

# T-216 게임 페이지 스크롤 등장과 게임 줄 호버(PV 버튼)

> 승인일: 2026-11-13 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
게임 페이지(`/games`, `/games/<연도>`)에만 F016 애니메이션이 아직 없다. 글 목록(T-124)·글 카드(T-125)와 같은 스크롤 등장·카드 호버를 게임 목록에도 적용해 사이트 전체 리듬을 맞춘다.

## 구현
1. **`components/shared/motion/hover-card.tsx`** — `overlay?: ReactNode` prop 추가. 움직이지 않는 바깥 div 안, 움직이는 안쪽 div 뒤에 그린다. PV 버튼(줄 전체를 덮는 투명 버튼)이 바깥 div의 자식이 되어야 ① 호버·누름 이벤트가 바깥 div로 전달되고 ② 버튼(클릭 영역)이 떠오르지 않아 가장자리 떨림·클릭 누락이 없다 (T-125 구조 유지).
2. **`app/globals.css`** `accent-hover-in-group` — 선택자에 `.group:has(:focus-visible)` 추가. 게임 줄은 `.group`이 아니라 안쪽 버튼이 포커스를 받으므로, 키보드 포커스 때도 테두리가 켜지게 함.
3. **`components/shared/game-card.tsx`**
   - PV 있음: 바깥 `div.group h-full` > `HoverCard className="border bg-card ... accent-hover-in-group" overlay={<GameTrailerDialog …/>}` > 줄 내용. 기존 `accent-hover` 제거.
   - PV 없음: 지금 구조 그대로 (움직임 없음). 줄 내용은 공통 조각으로 빼서 두 경우가 같이 씀.
   - "▶ PV" 표시 색: `group-hover:text-primary`에 `group-has-focus-visible:text-primary` 추가.
   - 다른 `.group` 조상이 없으므로 named group은 쓰지 않음.
4. **`components/sections/game-list.tsx`** — `post-list.tsx`와 같은 방식으로 `Reveal` 재사용: 상단 요약·PV 안내, 묶음 제목(h2)을 `Reveal`로 감싸고, 게임 줄은 `<Reveal as="li" delay={(index % 2) * STAGGER}>`.
5. **`components/shared/year-tabs.tsx`** — 탭에 `focus-visible:text-foreground` 추가. 크로스페이드는 T-122 래퍼가 이미 처리.

`game-year-view.tsx`, `app/games/*`는 변경 없음.

## 결정
- (2026-11-13) 떠오름·기울기는 PV가 있는 줄만. PV 없는 줄은 눌러도 반응이 없으므로 움직이지 않음.
- (2026-11-13) 미결 해결: 바 형태 게임 줄의 평점·한 줄 소감은 지금 그대로(값이 있으면 표시, 없으면 숨김).
- (2026-11-13) 미결 해결: `/games` 전체 보기에서 게임 줄에 연도를 표시하지 않음.
- (2026-11-13) 구현: `HoverCard`에 `overlay` prop 추가(제자리 바깥 div에 그림 — PV 버튼용). `accent-hover-in-group`에 `.group:has(:focus-visible)` 추가(안쪽 버튼 포커스 때도 테두리). 리뷰 반영: overlay 팝업(포털)에서 올라온 pointermove는 무시해 팝업이 열린 동안 뒤의 줄이 기울지 않게 함. `:has` 선택자 범위(나중에 카드 안에 포커스 요소가 생기면 같이 강조됨)는 사용자 결정으로 그대로 둠.

# T-203 프로필 섹션

> 승인일: 2026-11-13 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
T-201에서 `content/profile.json` 로더(`getProfile`, `lib/content.ts`)가 만들어졌지만 `/about`에는 아직 스타터킷 설명(컴포넌트 계층·사용 라이브러리)이 남아 있습니다. 이 작업으로 `/about` 상단에 운영자 프로필(사진 또는 이니셜 아바타, 이름, 한 줄 소개, 관심 분야, 지금 공부 중인 것)을 보여 주고 스타터킷 내용을 지웁니다.

## 결정 (사용자 답변)
- 배치: 사진 왼쪽 + 글 오른쪽, 모바일(375px)에서는 사진 위·글 아래로 쌓임
- 관심 분야·공부 중인 것: shadcn `Badge`(칩)로 가로 나열
- 이니셜: 첫 글자 1자 (`"HanS"` → `H`). 띄어쓰기로 나뉜 이름이면 단어 첫 글자 2개(`"Han Seo"` → `HS`), 영문은 대문자

## 변경 파일
1. **새 파일 `components/sections/profile-intro.tsx`** (서버 컴포넌트)
   - props: `profile: Profile` (`lib/content.ts`의 타입만 `import type`)
   - shadcn `Avatar`/`AvatarImage`/`AvatarFallback` 재사용, 크기는 `className`으로 키움(예: `size-24 sm:size-32`), 이니셜은 `font-heading` + `text-primary` 큰 글자
   - `photo`가 있으면 `AvatarImage src={photo} alt={name}`, 항상 `AvatarFallback`(이니셜) 포함 → `photo`를 비우거나 로드 실패 시 이니셜. basePath 대응은 T-310
   - 이름은 페이지 `h1`, 한 줄 소개는 `p text-muted-foreground`
   - "관심 분야"·"지금 공부 중" 제목 + Badge 목록. 배열이 비어 있으면 그 줄을 통째로 숨김
   - 이니셜 계산 함수는 이 파일 안 작은 함수 (`Array.from`으로 한글·이모지 안전)
2. **`app/about/page.tsx`** 교체
   - 스타터킷 `layers`·`libraries`·`PageHeader`·`Section` 제거
   - `getProfile()` → `<ProfileIntro profile={profile} />`만 조립 (T-204~T-207에서 섹션 추가)
   - `metadata`: title "소개", description은 `generateMetadata`에서 `getProfile().name`을 넣은 소개 문구

애니메이션(스크롤 등장)은 T-215 범위라 이번엔 넣지 않습니다.

# T-309 태그 페이지 sitemap 추가와 페이지별 메타데이터·OG 정보

> 승인일: 2026-11-14 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- sitemap(`app/sitemap.ts`)에 메뉴·글·게임 연도 페이지는 있으나 **태그 페이지(`/blog/tags/<slug>`)가 없음**.
- 블로그·글 상세·태그·게임 페이지는 이미 각자 title·description이 있지만, `openGraph`를 정하지 않아 레이아웃 값을 그대로 물려받음 → **모든 페이지의 og:title·og:description·og:url이 사이트 이름·설명·홈 주소로 같음**. (Next.js 16 메타데이터는 얕은 병합: 페이지가 `openGraph`를 정하면 레이아웃 `openGraph`는 통째로 대체 — `generate-metadata.md` "Merging")
- 사용자 결정: og:image는 **글 thumbnail이 있을 때만**, 페이지마다 **자기 자신 canonical** 넣음, 홈 문구는 **siteConfig 기본값 유지**.

## 변경

### 1. `lib/metadata.ts` (새 파일, 공통 함수)
- `baseOpenGraph` = `{ type: "website", locale: "ko_KR", siteName: siteConfig.name }`
- `pageMetadata({ title?, description?, path, openGraph? })` → `Metadata`
  - `title`·`description` (없으면 넣지 않아 레이아웃 기본값 사용)
  - `alternates.canonical: path` (metadataBase로 절대 주소가 됨)
  - `openGraph: { ...baseOpenGraph, title: title ?? siteConfig.name, description: description ?? siteConfig.description, url: path, ...openGraph }` — 얕은 병합 때문에 siteName·locale을 매번 다시 넣음
- 순수 함수 (fs 없음)

### 2. 페이지 메타데이터를 공통 함수로 교체 (문구는 그대로)
- `app/layout.tsx`: `openGraph`를 `{ ...baseOpenGraph, url, title, description }`로 정리 (값 동일)
- `app/page.tsx`(홈): `pageMetadata({ path: "/" })` — title·description은 기본값
- `app/blog/page.tsx`, `app/games/page.tsx`: 기존 title·description + `path`
- `app/games/[year]/page.tsx`: `path: /games/<연도>`
- `app/blog/tags/[tag]/page.tsx`: `path: /blog/tags/<slug>`
- `app/blog/[slug]/page.tsx`: `path: /blog/<slug>`, `openGraph: { type: "article", publishedTime, tags: 표시 이름 목록, images: thumbnail 있으면 [thumbnail] }`
- `app/not-found.tsx`는 그대로 (canonical 없음)
- 게임 전체·연도 페이지끼리 서로 가리키는 canonical은 두지 않음 (기존 결정 유지, 각자 자기 주소)

### 3. `app/sitemap.ts`
- `getAllTags()`로 `/blog/tags/<slug>` 추가, `lastModified` = 그 태그 글 중 가장 최근 작성일
- 반환 순서: 메뉴 → 글 → 태그 → 게임 연도

## 참고·주의
- og:image·canonical 경로는 metadataBase 기준 절대 주소가 되며 basePath는 붙지 않음 — 지금은 basePath가 비어 문제없음, 필요 시 T-310에서 함께 처리
- 새 패키지 없음

## 검증
1. `npm run lint`, `npx tsc --noEmit`, `npm run build`
2. `out/sitemap.xml`에 `/blog/tags/blog`·`devlog`·`shader` 포함 확인
3. 빌드 HTML에서 `<title>`·`description`·`og:*`·`canonical`이 페이지마다 다른지 확인, 글 상세는 `og:type=article`·`article:published_time`·`article:tag`

## 결정
- 2026-11-14: og:image는 글 thumbnail이 있을 때만(기본 이미지·빌드 생성 이미지 없음), 모든 페이지(404 제외)에 자기 자신 canonical, 홈 title·description은 siteConfig 기본값 유지.
- 2026-11-14: canonical·og:url·og:image에는 basePath가 붙지 않음 → basePath를 쓰게 되면 T-310에서 함께 처리.

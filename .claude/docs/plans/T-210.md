- 사용자 결정: 상태가 없는 게임은 **'플레이한 게임' 묶음**(맨 뒤), 카드는 **세로 표지 자리(3:4) + 제목 이니셜**(표지가 생기면 그 자리에 들어감).
- 재사용: `PageHeader`, `Container`, `Section`, shadcn `Card`·`Badge`, `buttonVariants`, `accent-hover`, `lucide-react`(StarIcon), `isNavActive`(하위 경로도 활성), 블로그 상세의 `generateStaticParams` + `dynamicParams = false` 패턴([app/blog/[slug]/page.tsx](app/blog/[slug]/page.tsx)).
- 애니메이션(스크롤 등장·카드 호버)은 T-216에서. 이번엔 넣지 않음.

## lib/games.ts에 추가 (정렬·집계)
- `STATUS_LABEL`: playing 플레이 중 / cleared 클리어 / dropped 중단 / wishlist 하고 싶은 게임
- `groupGames(games)`: 순서 플레이 중 → 클리어 → 중단 → 하고 싶은 게임 → **플레이한 게임(상태 없음)**. 묶음 안은 시작일 최신순, 시작일 없으면 뒤로 가고 제목순(`localeCompare("ko")`). 빈 묶음은 빼고 반환. 원본 배열은 바꾸지 않음(`toSorted`)
- `countGroups(games)`: 요약·연도 카드용 `[{ label, count }]` (0개 묶음 제외)

## 컴포넌트
- `components/shared/star-rating.tsx`: 별 5개 중 n개 채움(`fill-current text-primary`), `sr-only` "5점 만점에 n점" — 지금 데이터엔 평점이 없어 화면엔 안 나옴
- `components/shared/game-card.tsx` (서버): 세로 3:4 표지 자리
  - 표지 있으면 `next/image`(fill, alt ""), 없으면 제목 첫 글자를 크게 + `from-primary/15 via-card to-card` 그라데이션(장식, aria-hidden)
  - 제목(h3), 상태 배지(있을 때만: 플레이 중 = 포인트 색, 그 외 = secondary), 플랫폼 배지(여러 개, Mono), 평점·소감(있을 때만), 플레이 시간 "24.2시간", 날짜 "2026-01-01 ~ 2026-01-15" / 시작만 있으면 "2026-10-29 ~" (Mono, 없으면 줄째 숨김)
  - 링크 없음(게임별 상세 페이지는 범위 밖)
- `components/sections/game-list.tsx`: 상단 요약 "플레이 중 1 · 클리어 5 · 플레이한 게임 4", 묶음마다 h2 제목 + 개수 + 그리드(모바일 2열 · sm 3열 · lg 4열 · xl 5열). 0개면 "아직 기록한 게임이 없습니다"
- `components/shared/year-tabs.tsx`: 데이터가 있는 연도 링크(최신 먼저, 하나여도 표시), 현재 연도는 `aria-current="page"` + 포인트 색 밑줄
- `components/sections/game-cover-credit.tsx`: 표지가 있는 게임이 있을 때만 "표지 이미지 저작권은 각 게임사에 있습니다" + 게임별 출처 목록 (지금은 표지가 없어 안 보임)
- `components/sections/game-year-list.tsx`: 연도 카드(연도 크게 + 묶음별 개수, 카드 전체가 `/games/<연도>` 링크, `accent-hover`). 연도가 없으면 안내 문구

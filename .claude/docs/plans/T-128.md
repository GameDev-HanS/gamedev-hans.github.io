# T-128 스크롤 등장 감시·애니메이션 요소 분리

> 승인일: 2026-11-14 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- 2026-11-14에 스크롤 등장을 매번 재생(`viewport once: false`)으로 바꿨는데, `Reveal`은 **화면에 보이는지 재는 요소 = 움직이는 요소**다 (`fadeUp.hidden`의 `y: 8`, lib/motion.ts).
- 짧은 항목(게임 줄·자격증, 높이 약 40px)이 화면 위쪽 가장자리에 걸치면: 20% 미만 → 숨김(8px 내려감) → 다시 20% 이상 → 표시 → … 반복되며 깜빡일 수 있다 (코드 리뷰 지적, 미확인).
- `Stagger inView`는 바깥 요소(감시)에 transform이 없고 안쪽 `StaggerItem`만 움직여 이미 안전하다 (지금 사용처도 없음).

## 변경

### 1. `components/shared/motion/reveal.tsx` — 감시와 움직임을 분리
- 바깥: `as`("div" | "li") 그대로의 **일반 요소**(transform 없음)에 ref를 달고 `useInView(ref, { amount: 0.2 })`(motion/react)로 감시만 함.
- 안쪽: `motion.div`가 `data-motion`, `variants={fadeUp}`, `initial="hidden"`, `animate={inView ? "show" : "hidden"}`, `transition={{ inherit: true, delay }}`로 움직임.
- `className`은 **안쪽**에 붙이고 안쪽에 기본 `h-full`을 더함 → 지금 사용처의 레이아웃 클래스와 그리드 카드 높이 맞춤이 그대로 유지됨. ul/li 구조도 유지(바깥이 li).
- 사용처 변경 없음: post-list, game-list, certificate-list, career-timeline.

### 2. `components/sections/skill-stack.tsx` — dl 구조 때문에 Stagger로 교체
- `dl` 안에는 `dt`·`dd`를 감싸는 div가 한 겹만 허용돼서 Reveal의 안쪽 div를 넣을 수 없음.
- 분류 묶음 div를 `Stagger inView`(감시, transform 없음, `delay={index * 0.05}`, `gap={0}`)로 바꾸고 `dt`·`dd`를 `StaggerItem as="dt"`·`as="dd"`로 움직임.
- `components/shared/motion/stagger.tsx`: `StaggerItem`의 `as`에 `"dt" | "dd"` 추가.

### 바꾸지 않는 것
- 애니메이션 값(lib/motion.ts), 동작 줄이기, JS 꺼짐 대응(`data-motion`은 움직이는 안쪽 요소에), HoverCard·카드 클릭.

## 검증

2. 빌드 HTML에서 li > div[data-motion], 기술 스택 `dl > div > dt/dd[data-motion]` 구조 확인
3. 브라우저 확인: Playwright MCP가 이 세션에서 끊겨 자동 확인 불가 → 사용자가 모바일에서 확인 (MCP가 다시 연결되면 `/test`)

## 변경
1. `components/shared/video.tsx` (서버 컴포넌트, JS 없음)

   - src는 `https://`만 허용 — 아니면 빌드 오류. poster는 `withBasePath`(로컬 `/images/...`) 또는 https
   - 미지원 브라우저용 대체 문구 + 원본 링크
2. `mdx-components.tsx`에 `Video` 등록

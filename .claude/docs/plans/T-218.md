## Context
- 표지 이미지는 저작권 위험으로 보류(T-217). 대신 사용자 아이디어: **게임사 공식 유튜브 PV를 임베드**해서 보여 줌 — 영상 파일을 저장소에 올리지 않고, 업로더가 허용한 임베드 기능만 써서 훨씬 안전.
- 사용자 결정: 카드는 이니셜 그대로, **카드를 누르면 팝업에서 PV 재생**. 누르기 전에는 유튜브에 아무 요청도 보내지 않음(개인정보·속도).
- 사용자 요청: "들어가야만 볼 수 있는 건 별로" → **/games에서 바로 최신 연도 목록**을 보여 주고, 제목 아래 연도 목록(2026 · 2025 …)으로 바꿈. 연도 카드 페이지는 없앰.
- 재사용: `GameList`·`GameCard`·`YearTabs`·`PageHeader`([components/](components/)), shadcn `Dialog`([components/ui/dialog.tsx](components/ui/dialog.tsx), Base UI — `render` prop), `getGameYears`·`getGamesByYear`([lib/games.ts](lib/games.ts)).

## 변경
1. [lib/games.ts](lib/games.ts) 스키마: `trailer`(선택, 유튜브 영상 ID `^[A-Za-z0-9_-]{11}$`) 추가. [content/games/2026.json](content/games/2026.json)에 10개 ID 추가
2. 새 `components/shared/game-trailer-dialog.tsx` (`"use client"`): 카드 전체를 누르는 버튼(Dialog Trigger) + 팝업
   - 팝업은 **열렸을 때만** `<iframe src="https://www.youtube-nocookie.com/embed/<ID>?autoplay=1&rel=0">`를 그림(닫으면 사라져 재생도 멈춤), 16:9, `title="<게임> PV"`, `allow="autoplay; encrypted-media; picture-in-picture"`, `allowFullScreen`
   - 팝업 아래 "YouTube에서 보기" 링크(새 탭) — 연령 제한 등으로 임베드가 안 될 때 대비
   - 버튼 이름: "<게임> PV 보기", 키보드(Enter·Space)·Esc 닫기는 Dialog 기본 동작
3. [game-card.tsx](components/shared/game-card.tsx): `trailer`가 있으면 표지 자리 가운데에 ▶ 아이콘(장식)과 호버 시 포인트 색 테두리(`accent-hover`), 카드 내용을 `GameTrailerDialog`로 감쌈. 없으면 지금 그대로. 카드 내용 자체는 서버 컴포넌트로 두고 children으로 넘김
4. /games 바로 목록
   - 새 `components/sections/game-year-view.tsx`: 제목("<연도> 플레이 게임") + `YearTabs` + `GameList` + `GameCoverCredit` 묶음
   - [app/games/page.tsx](app/games/page.tsx): 최신 연도로 `GameYearView` (제목 메타데이터 "게임")
   - [app/games/[year]/page.tsx](app/games/[year]/page.tsx): 같은 `GameYearView`. 최신 연도 페이지는 `alternates.canonical: "/games"`(같은 내용 중복 방지)

   - [app/sitemap.ts](app/sitemap.ts): 최신 연도 `/games/<연도>`는 빼고(`/games`와 같음) 지난 연도만

## 검증
1. lint·typegen·tsc·build 통과, 잘못된 trailer ID(10자, 특수문자)면 빌드 실패 (스크래치 검증 스크립트에 케이스 추가)
2. 빌드 결과물 + Playwright:
   - 헤더 '게임' → `/games`에 바로 2026 목록(카드 10개), 연도 목록에 2026 활성
   - 페이지를 연 직후 네트워크에 youtube 요청 0건
   - 카드 클릭 → 팝업 열림, iframe src가 youtube-nocookie + 해당 ID, Esc로 닫으면 iframe 사라짐, 키보드 Tab→Enter로도 열림
   - "YouTube에서 보기" 링크 새 탭
   - `/games/2026` 접근 가능 + canonical `/games`, `/games/2020` 404
   - 임시 2025.json으로 연도 목록 2개·`/games/2025` 확인 후 삭제
   - 375px에서 팝업 폭 맞음·넘침 없음, 다크·라이트
3. 리뷰 → ROADMAP 체크 → `/commit-test`

## 수정 (2026-11-09, 구현·리뷰 반영)
- ▶ 표시는 표지 자리 오른쪽 아래. 카드 내용을 Dialog로 감싸는 대신 카드 위를 덮는 투명 버튼(형제 요소)을 둠 → 버튼 안에 제목(h3)·목록이 들어가지 않아 HTML 규칙에 맞고 화면 낭독기가 카드 내용을 그대로 읽음
- 팝업 닫기 버튼은 기본(영어 Close) 대신 한국어 '닫기' 이름으로 직접 둠
- 연도 페이지 설명은 연도별 문구('<연도>년에 플레이한 게임 기록')
- 연도 목록은 정렬 순서에 기대지 않고 최신 연도를 직접 계산
- 키보드 포커스 테두리: Tailwind v4의 outline-none은 선을 없애므로 outline-hidden + focus-visible:outline-solid

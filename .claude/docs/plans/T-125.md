# T-125 카드 호버 떠오름·기울기 공통 래퍼와 글 카드 적용

> 승인일: 2026-11-12 · 로드맵: [ROADMAP](../ROADMAP.md)

## Context
- 단계 1의 마지막 작업. 끝나면 단계 2·3의 P0 작업(T-201, T-301 등)을 시작할 수 있습니다.
- 지금 글 카드(components/shared/post-card.tsx)는 호버·포커스 때 `accent-hover`로 테두리가 포인트 색으로 바뀌고 옅은 그림자가 생깁니다. 썸네일은 1.05배 커집니다. 여기에 **떠오름 + 마우스를 따라 살짝 기울기 + 누름**을 더하고, 이 효과를 공통 래퍼로 만들어 프로젝트 카드(T-215)와 게임 줄(T-216)에서도 다시 씁니다.
- 기반: Motion(`motion/react`), 루트의 `MotionConfig reducedMotion="user"`(components/providers/motion-provider.tsx), 공통 값은 lib/motion.ts.

## 구현
1. **lib/motion.ts**: 호버 값을 추가합니다. `HOVER_LIFT = 4`(px), `HOVER_TILT = 3`(도, 로드맵 "약 4° 이하"), `HOVER_SPRING`(가벼운 spring, 예: stiffness 300 · damping 25).
2. **`components/shared/motion/hover-card.tsx`** (새 파일, `"use client"`)
   - `motion.div`(`h-full`)가 children을 감쌉니다. style: `rotateX`/`rotateY`(`useSpring` 값), `transformPerspective: 800`
   - `onPointerMove`: `pointerType === "mouse"`일 때만 카드 안의 마우스 위치(-0.5~0.5)에 따라 기울입니다. 위쪽에 마우스가 있으면 위가 뒤로 가는 방향입니다. `onPointerLeave`에서 0으로 돌아갑니다.
   - `whileHover={{ y: -HOVER_LIFT }}`: Motion의 hover는 터치를 무시하므로 터치 기기에서는 떠오르지 않습니다.
   - `whileTap={{ scale: 0.98 }}`: 누름 효과입니다. 터치 기기에서는 이것만 동작합니다.
   - 동작 줄이기: `useReducedMotion()`이 true이면 기울기 계산을 건너뜁니다. 떠오름과 누름은 `MotionConfig reducedMotion="user"`가 transform을 꺼서 자동으로 빠집니다. 테두리(`accent-hover`)는 CSS라서 그대로 보입니다.
   - transform만 쓰므로 주변 카드가 밀리지 않고, 링크 클릭과 키보드 포커스는 안쪽 `<Link>`가 그대로 처리합니다.
3. **post-card.tsx**: 서버 컴포넌트를 유지한 채 `<HoverCard>`로 기존 `<Link>`를 감쌉니다. 테두리와 그림자는 기존 `accent-hover`를 그대로 씁니다. 썸네일 확대는 유지합니다.
   - 홈 최근 글(recent-posts.tsx)과 블로그 목록(post-list.tsx)은 PostCard를 쓰므로 둘 다 자동으로 적용됩니다. 바깥 `Reveal`/`StaggerItem`(li)과 안쪽 HoverCard는 서로 다른 요소라서 등장 transform과 호버 transform이 겹치지 않습니다.

## 결정
- 2026-11-12: 동작 줄이기에서 `whileHover`·`whileTap`을 직접 끔. `MotionConfig reducedMotion="user"`는 transform을 없애지 않고 애니메이션 없이 즉시 적용하기 때문(테스트에서 4px 떠오름이 남는 것을 발견)
- 2026-11-12: `whileTap`을 쓰면 Motion이 감싼 div에 `tabindex="0"`을 붙여 Tab이 카드마다 두 번 멈추고 하이드레이션 불일치도 생김 → `tabIndex={-1}`로 막음 (포커스는 안쪽 링크만). CSS `press`(:active)는 터치에서 안정적이지 않아 누름은 Motion으로 유지
- 2026-11-12: 값 — 떠오름 4px, 기울기 최대 3°, 누름 0.98배, spring stiffness 300 · damping 25, 원근 800px(`HOVER_PERSPECTIVE`)
- 2026-11-12 (리뷰 반영): 구조를 **링크(제자리, `.group`) > HoverCard 바깥 div(제자리, 호버·누름·마우스 위치 받음, 호버 중 z-10) > 안쪽 motion.div(움직임, 테두리)**로 바꿈. 이유: 움직이는 요소가 직접 호버를 받으면 아래 가장자리에서 떨리고, 링크까지 떠오르면 아래 4px 띠에서 테두리가 꺼지고 클릭이 안 됨(테스트에서 발견). 기울기는 움직이지 않는 바깥 크기로 계산
- 2026-11-12: 테두리 강조는 새 유틸리티 `accent-hover-in-group`(globals.css) — 바깥 `.group`의 hover·focus-visible 때 켜짐. 프로젝트 카드(T-215)·게임 줄(T-216)도 같은 방식으로 씀
- 2026-11-12: 떠오름·누름은 variant 라벨 전파 대신 바깥의 `onHoverStart/End`·`onTapStart/onTap/onTapCancel` 상태를 안쪽 `animate`로 넘김 — 라벨 전파는 마우스로 호버 중 누르면 누름이 전달되지 않았음
- 2026-11-12: 호버 중 동작 줄이기가 켜지면 남은 기울기를 0으로 되돌림
- 2026-11-12: 참고 (재리뷰) — `accent-hover-in-group`은 가장 가까운 `.group`이 아니라 바깥 조상 `.group` 어느 것이든 호버되면 켜짐. T-215·T-216에서 카드를 다른 `.group` 안에 넣으면 named group(`group/card`)으로 바꿀 것

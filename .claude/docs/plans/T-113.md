# T-113 본문 타이포그래피와 MDX 요소 스타일

> 승인일: 2026-11-09 · 로드맵: [ROADMAP](../ROADMAP.md)

## 변경
- `@tailwindcss/typography`(dev), `app/globals.css`에 `@plugin "@tailwindcss/typography";`
- 본문 감싸개: `prose dark:prose-invert max-w-none` + 링크 시안, 제목·목록·인용·인라인 코드 간격
- `mdx-components.tsx`: `img`는 `max-w-full h-auto`, 외부 링크는 새 탭 + `noopener noreferrer`
- 코드 블록 패널·하이라이트는 T-301

## 결과 (2026-11-09, T-110~T-113 공통 확인)
- 빌드: `○ /blog`, `● /blog/hello-world`, prose CSS 생성 (`@plugin "@tailwindcss/typography"`가 Turbopack CSS 처리에서 동작)
- `/blog`: 탭 제목 "블로그 | HanS Dev Log", "블로그" 메뉴 강조, 카드(썸네일 없는 글은 그라데이션), 카드 클릭 → 상세, 실제 마우스를 올리면 네온 테두리·글로우(`page.mouse.move`로 확인), 375px 1열·가로 스크롤 없음
- 상세: 탭 제목 = 글 제목, 날짜·요약·태그·대표 이미지, "목록으로" → `/blog`, `/blog/nope` → 404 GAME OVER
- 본문(임시 글로 확인 후 삭제): 링크 네온 시안(다크·라이트), 외부 링크 새 탭 + `noopener noreferrer`, 내부 링크는 새 탭 아님, 인용 마젠타 세로줄·기울임 없음, 인라인 코드 배경·따옴표 없음, 가로 2400px 이미지가 본문 폭(704px / 모바일 328px)에 맞춰짐
- 참고: 콘솔 404 1건은 메뉴 "게임" 링크 미리 불러오기(게임 페이지 T-213 전이라 정상). 대표 이미지 LCP `loading="eager"` 권장 경고 → 상세 대표 이미지는 `priority`로 처리, 카드 썸네일은 목록 첫 화면 성능 개선 때 검토
- 참고: 테스트 중 페이지가 저절로 다른 주소로 이동하는 현상이 간헐적으로 있었으나, `history.pushState`·클릭·키 입력 감시에 아무것도 기록되지 않았고 같은 조건에서 재현되지 않음 (사이트 코드에 자동 이동 없음) → 테스트 도구 쪽 현상으로 판단

## 수정 (2026-11-09, 리뷰 반영)
- 카드 썸네일 `alt=""` (카드 링크 이름에 제목이 이미 있어 중복 방지)
- MDX 링크: `//example.com`(프로토콜 상대 주소)은 외부 링크로 판단해 새 탭
- MDX 이미지: `className`이 와도 `h-auto max-w-full`이 유지되도록 합침
- `getAllPosts`를 React `cache()`로 감싸 한 번의 렌더에서 파일을 한 번만 읽음
- **T-310 메모 (basePath):** Next 16 문서(`05-config/01-next-config-js/basePath.md`)상 `next/image`의 `src`와 MDX 본문 `<img src="/images/...">`에는 basePath가 자동으로 붙지 않음. 지금은 basePath가 비어 있어 문제없지만, T-310에서 basePath를 쓰게 되면 이미지 경로에 basePath를 붙이는 공용 함수가 필요함 (post-card, post-header, mdx-components의 img, 배경 음악 src는 이미 처리됨)
